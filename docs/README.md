# לוח השנה הפסטפרי — חבילת אתר סטטי

חבילה זו עומדת בפני עצמה. אין בה חשבון משתמש, איסוף נתוני שימוש, שרת חישוב,
תלות ב־CDN או מימוש Pastafari חלופי. כל החישוב נעשה בדפדפן באמצעות המנוע
המהיר וב־Web Worker.

## פרסום

יש להעלות את **תוכן התיקייה**, החל מן הקובץ `index.html`, לכל שירות אירוח
סטטי. כל הנתיבים יחסיים, ולכן החבילה מתאימה גם לתת־נתיב כגון GitHub Pages.

לבדיקה מקומית יש להפעיל שרת HTTP מתוך התיקייה, למשל:

```sh
python -m http.server 8080
```

לאחר מכן פותחים `http://localhost:8080/`. אין לפתוח את `index.html` ישירות
כ־`file://`, מפני שדפדפנים אינם מאפשרים כך Worker ו־Service Worker תקינים.

## התקנה ועבודה לא־מקוונת

הקובץ `manifest.webmanifest` מאפשר התקנה כאפליקציית PWA. ה־Service Worker
שומר את מעטפת האתר ואת המנוע לאחר טעינה מוצלחת ראשונה.

## שפות ו-i18n

הממשק הציבורי תומך כעת בעברית ובאנגלית באמצעות שכבת i18n נפרדת מהמנוע. סדר בחירת השפה הוא `?lang=...`, אחריו בחירה שמורה של המשתמש, אחריה `navigator.languages`, ולבסוף אנגלית. בחירת שפה ידנית נשמרת מקומית ונכתבת ל-URL בלי למחוק פרמטרים אחרים. פירוט הארכיטקטורה והוספת locale נוסף נמצאים ב-`I18N.md`.
