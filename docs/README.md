# לוח השנה הפסטפרי – חבילת אתר סטטי

חבילה זו עומדת בפני עצמה. אין בה חשבון משתמש, איסוף נתוני שימוש, שרת חישוב,
תלות ב־CDN או מימוש Pastafari חלופי. כל החישוב נעשה בדפדפן באמצעות המנוע
המהיר וב־Web Worker.

## פרסום

יש להעלות את **תוכן התיקייה**, החל מן הקובץ `index.html`, לכל שירות אירוח
סטטי. כל הנתיבים יחסיים, ולכן החבילה מתאימה גם לתת־נתיב כגון GitHub Pages.

לבדיקה מקומית יש להפעיל שרת HTTP מתוך התיקייה, למשל:

```sh
python -m http.server 8080
```

לאחר מכן פותחים `http://localhost:8080/`. אין לפתוח את `index.html` ישירות
כ־`file://`, מפני שדפדפנים אינם מאפשרים כך Worker ו־Service Worker תקינים.

## התקנה ועבודה לא־מקוונת

הקובץ `manifest.webmanifest` מאפשר התקנה כאפליקציית PWA. ה־Service Worker
שומר את מעטפת האתר ואת המנוע לאחר טעינה מוצלחת ראשונה.

## שימוש באתר

- בפתיחה מוצג היום הפסטפרי הנוכחי והקציצה שמכילה אותו. היום הנוכחי נקבע לפי
  גבול היום האסטרונומי תלוי־המיקום המתועד ב־`ASTRONOMICAL-DAY.md`: אם מיקום
  מכשיר שכבר הותר זמין משתמשים בו, ואחרת מניחים את Kisurra ומציגים זאת בממשק.
  התאריך המבוקש מסומן גם בכותרת גדולה וגם בתג מפורש בתוך המשבצת; שאר
  המשבצות אינן לחיצות.
- בראש הדף אפשר לחפש תאריך לפי כל משפחות הלוחות שהחבילה מכירה: גריגוריאני,
  יוליאני, עברי, אסלאמי, היג'רי שמשי, סיני, הינדואי עתיק, סאקה, בודהיסטי
  תאילנדי, אתיופי, קופטי, יפני קיסרי, מינגואו, בהאי והספירה הארוכה של המאיה.
- בתוך „אפשרויות חישוב והשוואה” אפשר לשנות את **יום המעשה**. ברירת המחדל
  היא היום הפסטפרי הנוכחי לפי מיקום הצופה הפעיל, וכפתור האיפוס מחשב אותו
  מחדש לפי אותו מנגנון אסטרונומי.
- במסך מחשב אפשר להפעיל טבלת השוואה. בכל שורה נמצא אותו יום נשאל בדיוק;
  הטור הראשון משתמש ביום המעשה הראשון והטור השני ביום המעשה השני. ברירת
  המחדל היא היום מול מחר.
- הקישור „איך משתמשים באתר?” בראש הדף ובכפתור הצף מוביל למדריך המלא בתוך
  אותו דף.
- אזור **החיפוש ההפוך** מאתר יום מוחלט מתוך תאריך פסטפרי מלא. אפשר להשתמש
  ביום המעשה הפעיל, להזין יום מעשה מוחלט בכל אחד מן הלוחות הנתמכים, או
  לחפש על האלכסון `c=t` בתוך תחום סופי. אין הנחה שלפתרון יש יום יחיד.
- עורך **מערכת האילוצים** מאפשר להגדיר כמה משתני תאריך וקשרים ביניהם:
  תאריכים פסטפריים, שוויון, סדר כרונולוגי והפרשי ימים. גם תלות מחזורית
  מותרת כאשר האילוצים מצמצמים אותה לתחומים סופיים. כל פתרון שמוצג עבר
  אימות forward מלא במנוע הקנוני.
- מתחת ללוח הקציצה מוצגת סקירת **מבנה השנה** עבור יום המעשה הפעיל: אורך
  השנה, הטווח הגריגוריאני שלה, מספר הקציצות והחודשים, פירוט שמותיהם ואורכיהם,
  ומיקומם בתוך השנה. עבור חודשים מוצג גם מספר המקטעים הרצופים שבהם הם מופיעים,
  משום שחודש פסטפרי עשוי להיות שזור לאורך השנה ואינו בהכרח מקטע רצוף.

המרת קלט מלוחות אחרים נעשית בשכבת מתאמים קלה. גם החישוב הרגיל וגם
החיפוש ההפוך משתמשים באותו מנוע מהיר קנוני. ה־constraint solver וה־Worker
שלו הם שכבת חיפוש מעל אותו `F(c,t)` ואינם מימוש חלופי של הלוח.

### משמעות תוצאות החיפוש ההפוך

- `complete: true` ותוצאה ריקה פירושם שהוכח שאין פתרון בתחום הסופי שנבדק.
- `complete: true` עם פתרונות פירושו שכל הפתרונות בתחום מוצגים.
- `complete: false` פירושו שהחיפוש נעצר לפני הוכחת שלמות. גם כאשר טרם נמצא
  פתרון, אין להציג מצב כזה כ״אין פתרון״.
- `maxSolutions` ו־`maxScanned`, אם המשתמש הגדיר אותם, עשויים להחזיר פתרונות
  מאומתים חלקיים. timeout וביטול מפסיקים את הבקשה ואינם שקולים לתוצאה ריקה.
- `SAME_AS_TARGET` (`c=t`) דורש תחום חיפוש סופי. מערכת מחזורית שאינה ניתנת
  לצמצום לתחום סופי נדחית במקום להתחיל חיפוש בלתי־מוגבל.

פרטי מודל האילוצים וה־API נמצאים ב־`REVERSE-CONSTRAINTS.md`.

## זהות הגרסה

- מקור המנוע: `pastafari-calendar`, ענף `main`.
- `engine/pastafari-calendar-fast.js` באתר הוא עותק byte-for-byte של
  `browser/pastafari-calendar-fast.js` מן המאגר, ולא build מצומצם או מימוש
  נוסף. בדיקת parity אוטומטית אוכפת זאת.
- SHA-256 של קובץ המנוע הקנוני בעת שילוב החיפוש ההפוך:
  `61318bc0813579f8d703737716704c467b87f2492213c2a1bd0970d9bc9f421b`.
- גם `pastafari-constraints-client.js`, `pastafari-constraints.js` ו־
  `pastafari-reverse-worker.js` מסונכרנים מן המקבילות הקנוניות תחת `browser/`.
- תקרת אורך השנה נשארת 5778 ימים.

הקובץ `SHA256SUMS.txt` מאפשר לבדוק שלא חל שינוי בקבצים לאחר האריזה.

## פרטיות וייחוס

האתר והחבילה אינם מציגים שם של אדם או של מחולל. היסטוריית Git וקובצי סביבת
עבודה אינם כלולים. תנאי ההפצה נמצאים ב־`LICENSE`.

## שפות ו-i18n

הממשק הציבורי משתמש בשכבת i18n נפרדת מהמנוע. מקור האמת לרשימת ה־locales
הפעילים הוא `LOCALES` שב־`i18n/registry.js`; בעת עדכון זה רשומים בו 72 משאבי
locale. בדיקת הכיסוי המובנית היא מבנית — היא בודקת מפתחות וערכים חסרים — ואינה
כשלעצמה אישור לאיכות לשונית. סדר בחירת השפה הוא `?lang=...`, אחריו בחירה שמורה
של המשתמש, אחריה `navigator.languages`, ולבסוף אנגלית. בחירת שפה ידנית נשמרת
מקומית ונכתבת ל־URL בלי למחוק פרמטרים אחרים. שמות הקציצות והחודשים מוצגים לפי
מזהים יציבים ומועברים למנוע בשמות הפנימיים הקנוניים בלבד. כל 72 ה־locales
מגדירים גם במפורש את 96 מפתחות `reverse.*`; לממשק החיפוש ההפוך אין טבלת fallback
נפרדת. פירוט הארכיטקטורה והוספת locale נוסף נמצאים ב־`I18N.md`.
