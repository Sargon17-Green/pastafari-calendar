## Normative calendar domain

The Scroll (`sources/מגילת העיתים.md`, lines 893–954 and footnote 14 at 1109–1113) defines the month-weaving domain used by the calendar:

- 3..47 months per year;
- every month length is 4..123 days;
- first appearances are ordered by month number;
- last appearances are ordered by month number;
- legal weavings are ordered position-wise lexicographically by month number;
- DP prefix counting/unranking is allowed only if it preserves that explicit enumeration order.

This means month length `1` is not a legal Pastafarian calendar month length, but the exported component may still have a wider public software contract if its constructor accepts it.

## Public component contract before Update 14

The exported `MonthWeavingCounter` constructor accepted any non-empty Array of positive integer Number lengths. It exposed `count` and `unrank`; the declaration had no `rank` method. The real calendar call sites still supply only lengths generated by bounded composition over 4..123, so the defect is a public component-domain defect rather than a legal-calendar output defect.

The sealed chronicle owns the old jagged `h` DP table, completion counter and lexicographic unranker. Those mechanisms were not replaced.

## Independent reference

`verification/update14/month-weaving-reference.mjs` is deliberately brute-force and imports no production counter/helper/fixture. For tractable domains it:

1. enumerates every multiset permutation;
2. filters by first-appearance and last-appearance order;
3. sorts survivors position-wise lexicographically;
4. defines count/rank/unrank from that list.

## Before-fix differential and minimal counterexample

`artifacts/month-weaving-domain-before.json` scanned 500 vectors: 1..4 months, lengths 1..5, total length <=12. It found 268 failing accepted public domains.

Minimal counterexample:

```text
lengths = [2, 1]
accepted = true
production count = 2
reference count = 1
first ghost rank = 1
error = {'name': 'Error', 'message': 'ניסיון לסיים חודש שלא לפי סדר ההופעות האחרונות'}
```

Classification: **COUNT_BUG_GHOST_RANK_SPACE**. The old DP counts a singleton month as if its opening and closing could be separated, even though its only appearance is simultaneously first and last.

No small-domain mismatch was found when all tested lengths were >=2. The normative calendar domain 4..123 is therefore not implicated by the reproduced defect.

## Fix — preserved spaghetti / ghost-rank detour

The public positive-length contract was preserved rather than narrowed. `browser/month-weaving-domain-detour.js` installs a wrapper around the sealed counter.

A singleton month is a hard separator: all earlier months must finish before its sole position and all later months must start after it. For a poisoned domain the wrapper therefore splits the vector into non-singleton legacy islands separated by fixed singleton labels.

```text
old counter still owns every island
→ old count values form mixed-radix digits
→ public count is their product
→ public unrank translates a contiguous public rank into legacy island ranks
→ old unrank runs unchanged inside each island
→ singleton separators are stitched back in
→ public rank performs the inverse translation using the old h/comb completion census
```

Domains without `1` continue directly through the original count/unrank path. Production never enumerates the weaving space. A WeakMap caches poisoned-domain ledgers; no temporary global patch is installed during rank/unrank calls.

A public `rank(weaving)` method was added to complete the component contract and its type declaration.

The standalone API does not expose `MonthWeavingCounter`; its authoritative Worker reaches month weaving only through legal calendar-generated lengths 4..123. `scripts/build-standalone.mjs` strips the public-only Update 14 detour while bundling that Worker. Removing the three Update 14 source additions from `browser/pastafari-calendar-core.js` was verified byte-for-byte to reproduce the uploaded baseline core input.

A canonical local rebuild could not be executed in this container because `esbuild@0.28.2` is unavailable locally. The checked-in standalone artifacts were not changed. Static standalone artifact tests passed.
