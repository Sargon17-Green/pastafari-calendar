# Update 9 — SHA manifest completeness reconciliation

## Scope

This is a CI-reconciliation patch after Update 9. It does not change the calendar conversion logic, generated standalone bundles, public API behavior, or Update 9 arithmetic/reference code.

## Observed CI failure

The failing job was `node-test`, step:

```text
node scripts/check-sha-manifest-completeness.mjs
```

The preceding `sha256sum -c SHA256SUMS.txt` step passed, but the completeness step failed because many tracked `artifacts/` files were absent from the root `SHA256SUMS.txt` manifest.

## Root cause

`SHA256SUMS.txt` was generated by `scripts/checksums.mjs`, whose repository checksum policy still excluded `artifacts/`. The newer CI completeness check compares the root manifest against `git ls-files` and therefore requires every tracked file, excluding `SHA256SUMS.txt` itself, to be listed.

So the repository had an internal policy mismatch:

```text
checksums generator: excludes artifacts/
CI completeness check: requires tracked artifacts/
```

## Fix

The repository checksum exclusion no longer excludes `artifacts/`. Transient/local-only paths remain excluded, including `.git/`, `node_modules/`, Python cache files, and `.tgz` package tarballs.

The root checksum manifest was regenerated after this policy correction.
