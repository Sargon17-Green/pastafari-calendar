# বাংলা QA — পুরো সাইট

## এই ভাষা-পর্যায়ের নির্দেশনা

শুধু বাংলায় কাজ করুন। Pastafari Calendar-এর `bn-BD` locale-এ দেখা যায় এমন সব লেখা পরীক্ষা করুন; শুধু `/about/` নিবন্ধ নয়। বিশেষভাবে খুঁজুন:

- হিন্দি, ইংরেজি বা অন্য ভাষার অনিচ্ছাকৃত অবশিষ্ট লেখা;
- আক্ষরিক অনুবাদের গন্ধ, অস্বাভাবিক বাক্যগঠন বা বাংলায় অপ্রাকৃতিক শব্দচয়ন;
- মূল ইন্টারফেস, ব্যবহার নির্দেশিকা, বছর-দৃশ্য, বিপরীত অনুসন্ধান ও `/about/`-এর মধ্যে পরিভাষাগত অসামঞ্জস্য;
- বানান, কারক, সংখ্যা, যতিচিহ্ন ও বাংলা রীতির সমস্যা;
- অনুপস্থিত locale key, যা runtime-এ ইংরেজিতে fallback ঘটাতে পারে;
- `{placeholder}`, সূত্র, identifier, hash, স্থির সংখ্যা বা canonical নামের অনিচ্ছাকৃত পরিবর্তন;
- অনুবাদের সময় stable HTML ID বা deep link বদলে যাওয়া।

কোনো লেখা শুধু বোঝা যায় বলে অনুমোদন করবেন না। সেটি যেন স্বাভাবিক বাংলায় প্রথম থেকেই লেখা হয়েছে এমন শোনায়। সত্যিকারের অ্যালগরিদমিক নাম, API নাম ও identifier অপরিবর্তিত রাখুন; সাধারণ প্রযুক্তিগত গদ্য বাংলায় লিখুন।

## পাওয়া সমস্যা

`bn-BD`-এর মূল UI মোটের ওপর আগেই স্বাভাবিক বাংলায় ছিল এবং হিন্দি মিশ্রণের প্রমাণ পাওয়া যায়নি। তবে কয়েকটি কাভারেজ সমস্যা ছিল:

- `manifest.defaultDescription` সম্পূর্ণ ইংরেজিতে ছিল;
- `app.brand` অনুপস্থিত ছিল;
- `reverse.error.limitPositive`, `reverse.error.limitSafeInteger`, `reverse.error.absoluteDateField` অনুপস্থিত ছিল।

এসব এখন স্পষ্ট বাংলা মান পেয়েছে।

Canonical নামগুলোর আলাদা পর্যালোচনায় দেখা গেছে সেগুলো বাংলায় মোটের ওপর যথাযথ ও স্বাভাবিক: যেমন `শিয়াল`, `কিডনি`, `গম`, `নদী`, `তামা`, `রূপা`, `বালি`, `বাটি`, `ফোঁটা`, `দ্বার`। তাই কেবল অন্য ভাষা থেকে আলাদা দেখানোর জন্য সেগুলো বদলানো হয়নি।

`/about/` নিবন্ধের মূল সমস্যা ছিল প্রচুর সাধারণ ইংরেজি প্রযুক্তিগত গদ্য। উদাহরণ: `canonical`, `implementation`, `selection space`, `modulo bias`, `rejection sampling`, `probability theorem`, `physical moment`, `server address`, `generic injectivity`, `side information`, `computational core`, `search problem` ইত্যাদি।

এগুলো স্বাভাবিক বাংলা বৈজ্ঞানিক ও প্রযুক্তিগত ভাষায় পুনর্লিখন করা হয়েছে। উদাহরণস্বরূপ:
- `canonical` → `প্রামাণ্য`
- `implementation` → `বাস্তবায়ন`
- `selection space` → `নির্বাচন ক্ষেত্র`
- `generic injectivity` → `সাধারণ ক্ষেত্রে এক-একতা`
- `generic invertibility` → `সাধারণ ক্ষেত্রে বিপরীতযোগ্যতা`
- `side information` → `পার্শ্বতথ্য`
- `upper bound` → `ঊর্ধ্বসীমা`
- `physical moment` → `ভৌত মুহূর্ত`
- `absolute address` → `পরম ঠিকানা`

`Short Choice`, `Wide Choice`, `SAVE`, `Pastafarian Calendar Seer`, API/CLI নাম, সূত্র এবং code identifier অপরিবর্তিত রাখা হয়েছে।

দ্বিতীয় ভাষাগত পর্যায়ে atlas/statistics অংশও স্বাভাবিক করা হয়েছে:
- `median` → `মধ্যক`
- `structural month` → `কাঠামোগত মাস`
- `contiguous segment` → `অবিচ্ছিন্ন খণ্ড`
- `corpus` → `তথ্যসমষ্টি`
- `span` → `বিস্তার`

কয়েকটি বাংলা কারক-সংযোগও ঠিক করা হয়েছে, যেমন `শাখা-এ`, `সম্মিলন-এ`, `পুনর্গঠন-এর`, `অর্থ-এ` ইত্যাদি।

জ্যোতির্বৈজ্ঞানিক অংশে সাধারণ ইংরেজি গদ্য সরিয়ে `শুক্র`, `সময় অঞ্চল`, `দিবালোক-সাশ্রয়ী সময়` ইত্যাদি বাংলা রূপ ব্যবহার করা হয়েছে।

## সংশোধনের পর যাচাই

- ইংরেজি locale-এর সব 258 message key-এর স্পষ্ট বাংলা মান আছে।
- সব `{placeholder}` সেট ইংরেজি চুক্তির সঙ্গে হুবহু মেলে।
- `/about/`-এ ঠিক 29টি stable ID আছে; কোনোটি অনুপস্থিত, অতিরিক্ত বা দ্বৈত নয়।
- দুইটি semantic table-এ 19 + 9 body row বজায় আছে।
- সব বাধ্যতামূলক formula, hash, স্থির সংখ্যা ও identifier অক্ষুণ্ণ।
- অনিচ্ছাকৃত হিব্রু লেখা নেই।
- HTML, comment, `code` ও formula বাদ দিলে দৃশ্যমান গদ্যে আর অনিচ্ছাকৃত ASCII ইংরেজি prose নেই।

## অবস্থা

পাঠ্য-স্তরের semantic ও linguistic QA সম্পন্ন। Render/visual smoke, 390px মোবাইল পরীক্ষা এবং চূড়ান্ত `PASS` আলাদা পরবর্তী পর্যায়ে থাকবে।
