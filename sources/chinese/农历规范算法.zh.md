## 3. 项目内中文算法文本

以下文字是项目维护文本，用中文记录要实现的算法；它不是国家标准或 CALENDRICA 的逐字复制。

### 3.1 坐标

1. 所有换算先归约到同一整数日轴。项目日轴与儒略日号的关系必须显式写出，不能在算法中混用 JDN、Rata Die、Unix time 或本地时区日期。
2. 中国历法内部采用 fixed day / Rata Die 型整数日；项目中的 JDN 与 fixed day 之间应使用常量偏移转换。
3. 计算农历月首、节气、岁首时只允许使用确定的天文/算术函数；不得调用 `Intl`、ICU、本机时区或本机语言环境作为规范真值。

### 3.2 时区与地点

1. 农历朔日和节气按中国地点的标准时日确定。
2. 1929 年以前使用北京地方平太阳时对应的时区偏移；1929 年及以后使用 UTC+8。
3. 该时区只用于把天文时刻落入中国标准日期；machine-readable 输出本身不依赖调用机器的本地时区。

### 3.3 朔与月份

1. 每个农历月始于一次朔所在的中国标准日期。
2. 月内日期从 1 开始计数；朔日为初一。
3. 相邻朔日之间的日数即该农历月长度；通常为 29 或 30 日。
4. 月份编号从 1 开始。闰月不另取新编号，而是复用前一常规月份的编号，并以布尔字段 `leap=true` 明示。

### 3.4 中气、冬至与岁

1. 太阳黄经每隔 30° 的时刻构成中气序列。
2. 农历十一月所在的月必须包含冬至所在的中气。
3. 一个“岁”以一个冬至附近的十一月为参照，到下一个冬至附近的十一月为止。
4. 若相邻两个十一月之间含有十三个朔月，则该岁存在一个闰月。
5. 在含闰月的岁中，第一个不含中气的月为闰月；闰月使用其前一个月的月号，并设置 `leap=true`。

### 3.5 年、干支与周期

1. 年以六十甲子为周期。
2. 结构化输出必须包含：`cycle`、`yearInCycle`、`heavenlyStem`、`earthlyBranch`、`month`、`leap`、`day`。
3. `yearInCycle` 的范围为 1..60。
4. 天干由 `yearInCycle` 对 10 的数学模确定；地支由 `yearInCycle` 对 12 的数学模确定。负数输入必须使用数学取模，不得使用 JavaScript `%` 的截断余数语义。
5. `cycle` 允许为负。周期边界必须用 floor division 计算，不得用 toward-zero truncation。

### 3.6 正向换算

给定 fixed day `d`：

1. 找到 `d` 所在农历年的上一农历新年 `ny`。
2. 找到 `d+1` 之前最近的朔日 `m`。
3. `day = d - m + 1`。
4. 从 `ny` 起数朔月，确定当前月序号。
5. 若该农历年含闰月，则找出第一个不含中气的月；当前月等于该月时 `leap=true`，否则为 `false`。
6. 由农历年起点相对中国历元的周年数确定 `cycle` 与 `yearInCycle`。
7. 由 `yearInCycle` 派生天干地支。

### 3.7 反向换算

给定结构化农历日期 `(cycle, yearInCycle, month, leap, day)`：

1. 验证 `yearInCycle` 在 1..60，`month` 在 1..12 或算法允许的月序列范围内，`day` 为正整数。
2. 由 `cycle` 和 `yearInCycle` 估计该农历年的中点。
3. 由中点求该年的农历新年。
4. 顺序枚举该年朔月，匹配 `month` 与 `leap`。
5. 用匹配月首加 `day-1` 得到 fixed day。
6. 再执行一次正向换算校验完全相等；若不相等，应抛出 RangeError，而不是静默规范化。

### 3.8 对 Intl/ICU 的地位

1. 旧的 `Intl.DateTimeFormat('u-ca-chinese')` 路径可以保留，用于装饰性输出、现代范围 sanity check 或旧 API 兼容。
2. `relatedYear` 不是规范结构，不足以表示 `cycle/yearInCycle`，不能作为核心真值。
3. 即使 `Intl` 抛错、返回错误 parts、返回本地化文本或被 monkey-patch，结构化规范结果也必须保持不变。

## 4. Foundation 判别器

项目必须继续使用《מגילת העיתים》中给出的 Foundation 判别器作为 port 完成条件：

```text
Foundation absolute day / JDN: -13334246
Foundation fixed day / Rata Die: -15055671
cycle: -643
yearInCycle: 57
heavenly stem / earthly branch: geng-shen
month: 1
leap: false
day: 22
```

任何候选 port 若不能重现该结果，不得接入 production。候选实现可以作为诊断工具保留，但不得伪装成已完成的规范实现。
